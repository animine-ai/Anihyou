- Release notifications from the extension source: an opt-in message at the calendar time when the source has not confirmed the episode yet, scope choice (watching, all, or custom list statuses), per-anime always/never, cover and title from AniList.
- Reliable background refresh: a periodic WorkManager job, exact alarms for due releases, restart/update/clock receivers and expedited delivery, so release checks reach an idle phone.
- Calendar tab: edge scroller with a dot for every day and a date bubble, dimmed entries for planned but unproven releases, focus on today at app start.
- Anime and manga lists in two sections (ready to watch on top, waiting below), a collapsing search bar that never moves the list, and a pull to refresh that keeps the rows in place.
- Matching of source series to AniList: season-aware rules, split seasons with the first AniList episode, generic-word titles, suggestions, a manual matching page and a hub whose run can be stopped with a second tap.
- Behind detection from the source for anime in parts, with the numbering learned from the list entries.
- Widget follows the calendar tab, refreshes in the background and redraws when the release refresh ends.
- Extension pages: pinned search, grouped diagnostics, details header with status, background installation of newer signed packages.
- AniList requests are throttled with Retry-After.
